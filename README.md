# E-Commerce Store

A full-featured online storefront for a clothing / fashion brand. Customers can browse a product catalog with categories, sizes, colors, and filters, search and favorite items, build a shopping cart, and check out with card payments. Accounts let customers register and log in, keep a profile and theme preference, and track their orders, returns, and shipping.

Behind the storefront is an admin dashboard for managing products, orders, users, messages, and archived items, plus a contact/messaging system so customers can reach the shop directly.

## Features

- Product catalog with categories, sizes, colors, and filters
- Search, favorites, and best-sellers pages
- Shopping cart and checkout with card payments
- Customer accounts (register / login) with profiles and theme preference
- Orders, returns, shipping info, and FAQ pages
- Admin dashboard: products, orders, users, messages, archive
- Contact us / messaging system
- Fully responsive UI with light/dark themes
